# Debal
This is platform that allows people to get room mates to rent a home with. 

The major problems we have seen so far are 
-The home renting price is rising in Ethiopia
-The existing practices on social media platforms to get roommates are not trust worthy 
-People do not tend to get another people with matching profiles on the internet 

The major features are 
-An authentication 
-profile and preferences filling 
-Fayda authentication for security and trust
-Automatic matching profiles and displaying on the home page
-manually searching people with certain features
-chatroom for people who matched one another
